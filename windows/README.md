# DualVPN на Windows

Здесь то же самое, что на macOS, но без приложения: только скрипт, который
поднимает оба туннеля и убирает за собой маршруты. Окна и значка в трее нет.

Проверялось меньше, чем macOS-версия, — считай это рабочим черновиком.

## Что нужно

* Windows 10 или 11, права администратора
* Python 3 — из Microsoft Store или python.org, при установке отметить
  «Add python.exe to PATH»
* `lib\bin\sing-box.exe` — сборка с AmneziaWG, см. README в корне
* конфиги в `conf\`, как на macOS

## Запуск

Двойной клик по `windows\vpn.cmd`. Права администратора он запрашивает сам —
открывать «PowerShell от имени администратора» вручную не нужно.

Другой личный сервер — имя файла из `conf\` без расширения:

```
vpn.cmd my-server
```

`Ctrl+C` останавливает туннели и возвращает маршруты.

## Отличия от macOS

* нет приложения, значка и окна — только консоль
* нет фоновой службы: туннель живёт, пока открыто окно
* IPv6 не выключается, поэтому утечка по нему возможна
* корпоративные домены резолвятся через `conf\site.env`, как и на macOS

## Если не работает

Скрипт печатает, что делает, и на чём остановился. Частые причины: `python`
не в `PATH`, нет `sing-box.exe`, конфиг не прошёл проверку, или в `conf\`
несколько подходящих рабочих файлов — он должен быть один.
